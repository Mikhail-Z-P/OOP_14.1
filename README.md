# Проект "OOP"

## Описание:

Созданны классы [category.py](src%2Fcategory.py),  [product.py](src%2Fproduct.py)

Созданы подклассы Smartphone, LawnGrass, от класса [product.py](src%2Fproduct.py)

## Установка:

1. Клонируйте репозиторий: 
git clone https://github.com/Mikhail-Z-P/OOP_14.1


2. Установите зависимости:  
Активировать виртуальное окружение: poetry shell  
Установить все зависимости: poetry install


## Использование:
Запустите тесты:
pytest

Проверьте стиль кода: flake8
